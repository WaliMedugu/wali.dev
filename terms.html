Terms of Service

Welcome to Wali.Dev. These terms establish the rules of engagement, code delivery standards, and policies to protect both you (the client) and me (the developer) against abuse, scope creep, and workmanship complaints.

1. Fixed Scope & Scope Creep Prevention

All project builds and billing milestones are bargained based on a predefined set of written features and UI specifications. Scope creep is strictly prohibited. Any feature requests, layout changes, or extra pages requested after coding commences will not be worked on until we review the changes and agree upon a separate, additional budget.

2. Against Abuse & Harassment

I maintain high standards of professional respect. Hostile behavior, threats of feedback abuse, chargeback threats, or unreasonable demands for 24/7 instant messaging responses will result in immediate termination of the agreement. In such cases, all development ceases, and the license to use the written code is revoked until all work done is paid for in full.

3. Rules of Handover & Support

Code is delivered clean, commented, and hosted on Git repositories (GitHub/GitLab). I provide 3 months of free post-launch bug-fixing support for issues directly related to my code. This support does not cover:

  • Third-party platform or API deprecations (e.g. Google Maps, OpenAI API shifts).
  • Hosting or database provider failures (e.g. Supabase, Firebase service outages).
  • Bugs introduced by client-side modifications.

4. Limits of Liability

Wali.Dev operates on a best-effort basis for custom software engineering. Software is provided "as is" without warranty of merchantability or fitness for a particular purpose beyond the 3-month support agreement. I am not liable for any financial losses, service outages, or security breaches resulting from third-party hosting, package dependencies, or user database configurations.

5. Rules for Myself (Workmanship Commitment)

I hold my development process to strict engineering parameters:

  • No Template Bloat: I build clean layouts and clean database schemas tailored to your scale.
  • No Middle-Men: You deal directly with me. No project managers distorting the scope.
  • Honest Auditing: If a feature request is unnecessary or can be built simpler, I will advocate for the cheaper option.
